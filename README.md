# Sillylatro
The mod for none of your needs!
To start the mod go to your 'MODS' section of the main menu, and go into the settings of the mod


## Current Options!

-  bltro
    - Removes every occurrence of the letter 'a'.
-  Jalatro
    - Every word starts with a J.
-  Letter Sort
    - Every text has now been sorted a-z.
-  DVD Balatro
    - Causes your balatro window to bounce around like a dvd logo.
-  LIVE MARKIPLIER REACTION
    - Places Markiplier in the middle right of your screen where he'll react to your gameplay.
